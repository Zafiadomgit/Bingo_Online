═══════════════════════════════════════════════════════════════
  GUÍA SIMPLE PARA BLUEHOST (Paso a Paso)
═══════════════════════════════════════════════════════════════

Sigue estos pasos EN ORDEN. No te saltes ninguno.

═══════════════════════════════════════════════════════════════
PASO 1: SUBIR ARCHIVOS (5 minutos)
═══════════════════════════════════════════════════════════════

1. Abre File Manager en cPanel
2. Ve a: public_html
3. Crea una carpeta llamada: bingo
4. Abre la carpeta "bingo"
5. Sube TODOS los archivos de "bluehost-deploy" dentro de "bingo"
   (Puedes subir un ZIP y extraerlo ahí)

VERIFICA que dentro de "bingo" veas:
   ✓ app/
   ✓ components/
   ✓ package.json
   ✓ server.js
   ✓ .env.local


═══════════════════════════════════════════════════════════════
PASO 2: INSTALAR DEPENDENCIAS (10 minutos) ⚠️ CRÍTICO
═══════════════════════════════════════════════════════════════

1. En cPanel, busca "Terminal" (o solicita acceso SSH)
2. Abre el Terminal
3. Copia y pega estos comandos UNO POR UNO:

   cd public_html/bingo
   npm install --production
   npm run build

4. ESPERA a que termine cada comando
5. Si ves errores, cópialos y revísalos
6. Cuando termine, verás mensajes de éxito


═══════════════════════════════════════════════════════════════
PASO 3: CREAR APLICACIÓN NODE.JS (3 minutos)
═══════════════════════════════════════════════════════════════

1. En cPanel, busca "Node.js Selector"
2. Haz clic en "CREATE APPLICATION"
3. Llena el formulario:

   Node.js Version: 20.19.4 (o la más reciente)
   Application Mode: Production
   Application Root: /home/thebingo/public_html/bingo
   Application URL: /bingo
   Application Startup File: server.js
   Passenger log file: /home/thebingo/

4. Haz clic en "CREATE"
5. Si da error, verifica que la ruta sea exacta

PASO 5: REINICIAR Y VERIFICAR (2 minutos)
═══════════════════════════════════════════════════════════════

1. En Node.js Selector, encuentra tu aplicación
2. Haz clic en "RESTART" o "RELOAD"
3. Espera 30-60 segundos
4. Verifica que el estado diga "Running" o "Active"
5. Abre: https://thebingofortuna.com/bingo


═══════════════════════════════════════════════════════════════
SI AÚN NO FUNCIONA:
═══════════════════════════════════════════════════════════════

1. En Node.js Selector, haz clic en tu aplicación
2. Busca "View Logs" o "Logs"
3. Revisa los errores
4. Los errores más comunes:

   ❌ "Cannot find module"
      → Solución: Ejecuta "npm install" de nuevo

   ❌ "Port already in use"
      → Solución: Cambia PORT a otro número (ej: 3001)

   ❌ "Missing environment variables"
      → Solución: Agrega todas las variables del Paso 4

   ❌ "Build failed"
      → Solución: Ejecuta "npm run build" de nuevo
