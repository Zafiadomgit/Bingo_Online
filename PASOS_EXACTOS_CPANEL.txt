  PASOS EXACTOS EN CPANEL (Basado en lo que veo)
═══════════════════════════════════════════════════════════════

Veo que estás en cPanel. Sigue estos pasos EXACTOS:

═══════════════════════════════════════════════════════════════
PASO 1: SUBIR ARCHIVOS PRIMERO
═══════════════════════════════════════════════════════════════

1. En la sección "Archivos", haz clic en "Administrador de archivos"
2. Ve a: public_html
3. Crea una carpeta llamada: bingo
4. Abre la carpeta "bingo"
5. Sube TODOS los archivos de "bluehost-deploy" dentro de "bingo"
   (Puedes subir un ZIP y extraerlo)


═══════════════════════════════════════════════════════════════
PASO 2: INSTALAR DEPENDENCIAS (SSH)
═══════════════════════════════════════════════════════════════

1. En la barra de búsqueda (arriba a la derecha), escribe: "terminal"
2. O busca en "Avanzada" → "Terminal" o "SSH Access"
3. Abre el Terminal
4. Ejecuta estos comandos UNO POR UNO:

   cd public_html/bingo
   npm install --production
   npm run build

5. ESPERA a que termine cada comando


═══════════════════════════════════════════════════════════════
PASO 3: CREAR APLICACIÓN NODE.JS
═══════════════════════════════════════════════════════════════

1. En la sección "Software", busca "Setup Node.js App"
   (Tiene el logo de Node.js - círculo verde con "JS")
2. Haz clic en "Setup Node.js App"
3. Haz clic en "CREATE APPLICATION"
4. Llena el formulario:

   Node.js Version: 20.19.4 (o la más reciente disponible)
   Application Mode: Production
   Application Root: /home/thebingo/public_html/bingo
   Application URL: /bingo
   Application Startup File: server.js
   Passenger log file: /home/thebingo/

5. Haz clic en "CREATE"

PASO 5: REINICIAR Y VERIFICAR
═══════════════════════════════════════════════════════════════

2. Haz clic en "RESTART" o "RELOAD"
3. Espera 30-60 segundos
4. Verifica que el estado diga "Running" o "Active"

═══════════════════════════════════════════════════════════════
SI NO ENCUENTRAS "Setup Node.js App":
═══════════════════════════════════════════════════════════════

1. En la barra de búsqueda (arriba), escribe: "node"
2. Debería aparecer "Setup Node.js App" o "Node.js Selector"
3. Si NO aparece, tu plan puede no incluir Node.js
4. Contacta a Bluehost para habilitar Node.js en tu plan
