✅ PASO 1: Preparar Archivos (1 comando)
───────────────────────────────────────────────────────────────

En tu computadora, ejecuta:

   node preparar-para-bluehost.js

Esto hará TODO automáticamente:
✓ Instalará dependencias
✓ Construirá la aplicación
✓ Preparará todos los archivos listos

Espera 5-10 minutos a que termine.


✅ PASO 2: Subir Archivos a Bluehost
───────────────────────────────────────────────────────────────

1. Abre la carpeta "bluehost-deploy"
2. Selecciona TODOS los archivos y carpetas
3. Comprímelos en un ZIP
4. En cPanel → File Manager → public_html
5. Crea carpeta "bingo"
6. Sube el ZIP dentro de "bingo"
7. Extrae el ZIP
8. Elimina el ZIP


✅ PASO 3: Crear Aplicación Node.js
───────────────────────────────────────────────────────────────

1. En cPanel → "Setup Node.js App"
2. Haz clic en "CREATE APPLICATION"
3. Configura:
   - Application Root: /home/thebingo/public_html/bingo
   - Application URL: /bingo
   - Application Startup File: server.js
   - Node.js Version: 20.19.4
   - Application Mode: Production
4. Haz clic en "CREATE"
