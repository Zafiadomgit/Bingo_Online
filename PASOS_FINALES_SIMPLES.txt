───────────────────────────────────────────────────────────────

2. Selecciona TODOS los archivos y carpetas dentro
   (Incluye: app/, components/, node_modules/, .next/, etc.)
3. Comprímelos en un archivo ZIP
4. En cPanel → File Manager → public_html
5. Crea carpeta "bingo" (si no existe)
6. Sube el ZIP dentro de "bingo"
7. Extrae el ZIP (clic derecho → Extract)
8. Elimina el ZIP

   - Application URL: /bingo
   - Application Startup File: server.js
   - Node.js Version: 20.19.4
   - Application Mode: Production
4. Haz clic en "CREATE"
